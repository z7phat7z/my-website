Về tôi

Định nghĩa kỹ năng:

HTML
Ngôn ngữ đánh dấu siêu văn bản, dùng để tạo và cấu trúc nội dung trên trang web.
CSS
Ngôn ngữ định dạng trang tính, dùng để thiết kế màu sắc, bố cục cho website.
Git
Hệ thống quản lý phiên bản phân tán, giúp theo dõi thay đổi mã nguồn.

Kỹ năng của tôi

HTML5

Nắm vững thẻ Semantic, Form, Media.

CSS3

Thành thạo Flexbox, Grid và Box Model.

Git

Quản lý source code với GitHub.

JavaScript

Lập trình DOM và xử lý sự kiện.

Lộ trình học tập

  1. Nền tảng HTML/CSS.
  2. Thành thạo JS.
  3. Deploy website.
